# Resources

## Layout

    resources/
    ├── icons/
    │   └── app_logo.png
    ├── fonts/
    │   └── Roboto/
    │       ├── Roboto-Regular.ttf
    │       ├── Roboto-Medium.ttf
    │       ├── Roboto-Bold.ttf
    │       └── Roboto-Light.ttf
    └── themes/

## Rules

- The only image asset is `icons/app_logo.png`.
- The only font asset family is Roboto.
- The UI is text-based and monochrome (black and white).
- Icons use OS system icons or Unicode emoji.
- No other binary assets.
