# Ellindyer World Forge

World & Game Design Studio.

A desktop application for designing, managing, documenting, calculating,
validating, visualizing, and exporting game-world and game-design data.

World Forge is not a game engine. It defines game data and exports it to
game engines such as Unreal, Unity, and Godot.

## Status

Under active development.

## Platform

- Primary: Windows
- IDE: Visual Studio Code
- Language: C++ (C++20 or newer)
- Build: CMake
