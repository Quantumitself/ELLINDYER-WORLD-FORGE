# Coding Conventions

- C++20 or newer.
- 4-space indentation.
- LF line endings.
- File names in `PascalCase` for classes, `snake_case` avoided.
- Namespaces: `ellindyer::<subsystem>`.
- Prefer `std::` facilities over custom ones.
- Prefer composition over inheritance.
- One class per file where practical.
- No global mutable state.
- No `using namespace` in headers.
